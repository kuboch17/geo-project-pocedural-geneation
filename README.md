# Geo Game

A Unity geography game and procedural terrain experiment, created in 2023 with **Thomas Kaleta**. Fly around a generated globe and try to reach the requested country.

The project's main focus is **procedural mesh generation and heightmap-based vertex displacement**: constructing a sphere and shaping its surface using Earth's elevation data.

## Features

- Procedural globe constructed from six mesh faces.
- Adjustable mesh resolution and terrain amplitude.
- Terrain displacement based on a NASA topography and bathymetry heightmap.
- Flight around the globe with steering and speed controls.
- Country identification using a map texture and randomly selected country objectives.
- Main menu and pause menu.

### Controls

| Key | Action |
| --- | --- |
| `A` / `D` | Steer left / right |
| `S` | Switch to slower flight |
| `W` | Return to faster flight |
| Hold `Left Shift` | Boost while in faster flight mode |
| `Space` | Check the current country against the objective |
| `Esc` | Open the pause menu |

Forward movement is automatic. A successful country check selects a new objective.

## Open the project in Unity

### Requirements

- Unity Hub
- **Unity Editor 2021.3.20f1**, the version recorded in `ProjectSettings/ProjectVersion.txt`
- Git, or a downloaded ZIP of the repository

### Setup

1. Clone the project:

   ```bash
   git clone --branch game2 https://github.com/kuboch17/geo-project-pocedural-geneation.git
   ```

2. In Unity Hub, add the **`Geo Game Extreme`** folder inside the repository as an existing project.
3. Open it with Unity **2021.3.20f1** and allow the initial asset and package import to finish.
4. Open `Assets/Scenes/MainMenu.unity`.
5. Press **Play** in the Unity Editor.

The configured build scenes are `MainMenu.unity`, followed by `SampleScene.unity`.

## How terrain generation works

1. **Create six faces.** Each face starts as a square grid with a configurable resolution.
2. **Map the cube to a sphere.** Grid points are transformed into positions on a unit sphere.
3. **Sample the heightmap.** Each point's angular position determines where to sample the elevation texture.
4. **Displace the vertices.** Sampled height and terrain amplitude determine the radial offset.
5. **Build the mesh.** Triangles connect the vertices, and normals are recalculated for lighting.

Higher resolution adds more geometry; terrain amplitude controls how strongly elevation is exaggerated.

## Project structure

```text
Geo Game Extreme/
├── Assets/
│   ├── Scenes/          # Main menu and gameplay scenes
│   └── Scripts/         # Terrain generation, flight, and game logic
├── Packages/            # Unity package dependencies
└── ProjectSettings/     # Editor version and project configuration
```

### Key scripts

| Script | Responsibility |
| --- | --- |
| `Planet.cs` | Initializes the six faces and triggers mesh generation |
| `TerrainFace.cs` | Constructs sphere geometry and applies heightmap displacement |
| `movement_gravity.cs` | Moves and steers the aircraft around the globe |
| `speedCam.cs` | Changes flight speed and plays camera animations |
| `countryCheck.cs` | Detects the current country and checks objectives |
| `PauseMenuScript.cs` | Opens the pause menu and handles resume/menu actions |
